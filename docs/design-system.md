# デザインのルール

採用したデザインは「衝動の一点」（C案）です。値はすべて `design/tokens.css` にあり、見た目の正は `design/reference/` の参照HTMLです。この文書は、参照HTMLから読み取った決まりごとと、参照にない場面（タブレット、下層ページのスマホ、フォームのエラーなど）での判断の基準をまとめます。

## 1. 考え方

- **大きな明朝と細い罫線：** 太い明朝の大きな見出しと、1pxの罫線で組む
- **色は1つだけ：** 色を付けるのはアクセントの青（`--color-accent`）の1色だけ。点、主ボタン、募集の帯にしか使わない。これが社名の「衝動」＝「静けさの中の一点」を表す
- **写真やイラストを使わない：** 情報は文字、表、線で見せる
- **形：** 角を丸めるのはボタンとタグだけ。影、グラデーション、半透明の重ね、絵文字は使わない

## 4. レイアウト

- **コンテナ：** 本文の最大幅は1200px。左右の余白は `--gutter`（1440pxで120px、390pxで20px）
- **セクションの上下：** `--section-y`（1440pxで144px、390pxで80px）。募集の帯は `--section-y-sm`（120px → 72px）
- **セクションの区切り：** 1pxの `--color-line` の上罫線。黒い帯と青い帯は罫線なしで、地の色が切り替わる

参照で使っている並べ方の型は、次のとおりです。新しい画面もこの中から選んでください。固定幅の列は、1440pxの値です。画面が狭くなったら、§8の規則で組み替えます。

## 5. 罫線と形

- **細い罫線：** 行と行の間は `--color-line` の1px
- **太い罫線：** 一覧や表の一番上、3列の各列の頭は `--color-ink` の1px
- **角丸：** ボタンは高さの半分（完全な丸み）。タグは `--radius-pill`。それ以外の箱（PoCの2つの募集、注記の箱）は角を丸めない
- **影：** 使わない

## 6. モチーフ（罫線と一点）

- **組み方：** 横いっぱいの1px罫線（`--color-ink`）の上に、`--color-accent` の丸を置く。丸の中心を罫線に合わせる
- **大きさ：** トップは36px（スマホ24px）、下層ページは28px
- **位置：** コンテナ幅の63%（スマホ56%）
- **置き方の決まり：** 1ページに1つだけ置く。フッターの「衝動」の横の点は例外

ほかに、次の場所でもアクセントの点を使っています。いずれも「決断の一点」を表すので、新しい場所に増やさないでください。

- 依存関係の図で「どこで切るか」を示す点（「ID」と「委託先」の間）
- 比較表の自社の列の見出しの前の点
- 記事の要点の行頭の点

## 8. レスポンシブ

参照は1440px（PC）と390px（スマホのトップ）の2つです。その間は、次の規則で作ります。

| 幅 | 呼び方 | 主な変化 |
|---|---|---|
| 1440px以上 | 大きいデスクトップ | 参照（1440px）と同じ。コンテナは1200pxのまま中央に置く |
| 1024〜1439px | デスクトップ | 文字、余白、セクションの上下が `clamp()` で比例して縮む。列の並べ方は変えない。固定幅の列は、下の表のように縮める |
| 768〜1023px | タブレット | ヘッダーをメニューボタンにする。下の表のように列を組み替える |
| 767px以下 | スマホ | すべて1列。値は `ja-top-mobile.html` に合わせる |

**スマホでの決まり（`ja-top-mobile.html` から読み取ったもの）**

- **ヘッダー：** 高さ64px。下に罫線を引く（トップも含め全ページ）。この2つは768〜1023pxでも同じ
- **余白：** 左右20px、セクションの上下72〜80px
- **ボタン：** 主ボタンは幅いっぱいにする。隣のテキストリンクは、その下の中央に置く
- **募集の帯：** 条件の一覧をボタンの下に置く
- **フッター：** 会社情報、リンク2列、大きな「衝動」（120px）の順に縦に並べる
- **トップの見出し：** 1行目、罫線と点、右寄せの2行目、という構成を保つ

## 9. アクセシビリティ

- **目標：** WCAG 2.1 AA
- **コントラスト：** §2の組み合わせだけを使う
- **フォーカス：**
  - 通常の地では `outline: var(--focus-ring); outline-offset: var(--focus-offset)`
  - 黒い帯と青い帯の上では `var(--focus-ring-on-dark)`
  - `outline: none` にしない
- **押せる範囲：**
  - 最小44×44px（`--tap-min`）
  - 参照でこれより小さいもの（ラジオとチェックボックスの行は32px、スマホのフッターのリンクは36px）は、見た目を変えずに、余白で押せる範囲を44pxに広げる
- **見出しの階層：** 各ページのH1は1つだけにし、階層を飛ばさない。明朝の大きな一文（「計算はAIに…」など）は見出しではなく `<p>` のままにする（参照どおり）
- **言語：**
  - `html` に `lang` を付ける
  - 英語ページの中の日本語には `lang="ja"` を付ける
- **動き：** `prefers-reduced-motion: reduce` を尊重する
- **フォーム：** ラベルと入力欄を必ず結び付ける。エラーは文字で伝える（spec.md §6.3）
- **装飾：** 罫線の点、大きな「衝動」、矢印のアイコンは `aria-hidden="true"`

## 10. やらないこと

- アクセント以外の色を足す（エラー色を除く）
- 影、グラデーション、半透明、角の丸い箱
- 写真、ストックイラスト、絵文字
- 装飾のアニメーション、スクロールに合わせた演出
- 参照にない文言を、確認なしに足す
